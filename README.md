## 📖 About

SRWare Iron is a web browser developed by SRWare, a software vendor based in Germany. It is built on the open source Chromium engine, which means it shares the rendering core, extension support and general layout conventions of other Chromium browsers while applying its own configuration choices around telemetry, background reporting and default data collection. The 2026 edition continues the project's long-running approach: a clean tabbed interface, support for Chrome Web Store extensions, integrated ad and script controls, a private mode for temporary sessions, and frequent upstream Chromium security updates that keep the engine current.

## 🛠️ Troubleshooting

| Problem | Solution |
| --- | --- |
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes immediately | Reboot, close other installers, then run the setup file again as administrator. |
| Browser opens but pages do not load | Check your network or proxy settings, then confirm the Windows firewall is not blocking the app. |
| Tabs crash on heavy pages | Disable hardware acceleration in settings, or update your graphics driver. |
| Extensions will not install | Make sure the extension is available in the Chrome Web Store and that sync is not paused. |
| Profile or cache errors | Clear the browsing cache from settings, or remove the local profile folder and restart. |
| Update check fails | Confirm system date and time are correct, then retry the update from the browser's about page. |
